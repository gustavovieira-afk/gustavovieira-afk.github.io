Site: https://gustavovieira-afk.github.io

## Adicionar um projeto
1. Abra `script.js` e, na lista `PROJETOS`, copie um bloco `{ ... }` e mude os campos.
2. (Opcional) Coloque um print do projeto em `assets/` e preencha `imagem: "assets/nome.png"`.
3. Para mostrar botões no card: `links: [{ texto: "Ver código", url: "https://..." }]`.

## Mudar contatos
Edite o objeto `CONTATOS` no topo de `script.js`. Campo vazio (`""`) esconde o botão.

## Publicar uma atualização
```powershell
git add .
git commit -m "Adiciona projeto X"
git push
```
O site atualiza sozinho em 1 a 2 minutos.
